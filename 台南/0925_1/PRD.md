## 1. 產品概述

### 1.1 產品名稱

WordFlow

### 1.2 一句話介紹

> WordFlow 是一款利用間隔重複與每日短時練習，幫助使用者有效增加英文單字量的 iOS App。

### 1.3 產品願景

> 讓使用者能夠透過簡單、持續且有效的學習方式增加英文單字量，將每天背單字變成容易維持的習慣，並能實際應用在閱讀、聆聽與溝通中。

### 1.4 背景與問題

目標使用者目前可能遇到的問題：

- 單字書或單字表太長，不知道該從哪裡開始。
- 剛背完很快就忘記，缺少有效的複習時機。
- 只記得中文翻譯，無法在實際句子中使用。
- 學習過程沒有即時回饋，難以感受進步。
- 現有 App 功能太複雜、廣告太多，難以專注。

### 1.5 解決方案摘要

- 每天自動安排「新單字」與「待複習單字」。
- 依使用者熟悉度調整單字下次出現時間。
- 結合單字卡、發音、例句與小測驗。
- 顯示連續學習天數與掌握單字數，建立成就感。
- 提供清楚、無廣告干擾的學習流程，讓使用者每天可在 10 分鐘內完成任務。

## 2. 產品目標與非目標

### 2.1 本階段目標

MVP（最小可行產品）聚焦在：

1. 使用者能從內建字庫選擇要學習的內容。
2. 使用者能完成每日學習與複習。
3. App 能記錄每個單字的學習狀態。
4. 使用者能看到基本學習進度。
5. 在離線狀態下仍可完成主要學習流程。

### 2.2 非目標（MVP 暫不開發）

- 社群好友與排行榜。
- AI 自動生成所有課程內容。
- 多人即時對戰。
- iPad、Apple Watch 與 macOS 專用版本。
- 完整教師後台或班級管理。
- 多語言學習（MVP 可先專注英文）。

> 非目標可避免開發範圍不斷擴大，並不代表未來永遠不做。

## 3. 目標使用者

### 3.1 主要使用者

- 身分：想建立基礎英文單字量的高中生與大學生。
- 年齡：16～28 歲。
- 情境：每天可投入 5～15 分鐘，希望利用零碎時間學習。
- 需求：擴充日常與學校常用英文單字量。
- 痛點：容易半途而廢，不知道什麼時候該複習。

### 3.2 使用者人物誌（Persona）

| 欄位 | 內容 |
| --- | --- |
| 姓名 | 陳小安（虛擬人物） |
| 年齡／職業 | 20 歲／大二學生 |
| 學習目標 | 3 個月內掌握 500 個日常高頻單字 |
| 每日可用時間 | 通勤或課間 10 分鐘 |
| 目前做法 | 使用紙本單字書與手機備忘錄 |
| 最大困難 | 無法持續，也不知道哪些單字已經真正記住 |
| 使用動機 | 希望 App 直接安排今天要學與要複習的單字 |

## 4. 核心使用情境

### 4.1 核心使用者故事

- 作為新使用者，我希望選擇學習目標與每日單字量，以便 App 為我安排內容。
- 作為學習者，我希望用單字卡快速學習，以便在零碎時間完成任務。
- 作為容易忘記單字的人，我希望 App 自動安排複習，以便在適當時間加深記憶。
- 作為學習者，我希望看到今天的進度，以便知道還要完成多少。
- 作為學習者，我希望收藏難字，以便之後集中複習。

### 4.2 主要使用流程

1. 首次開啟 App。
2. 選擇學習目標、程度與每日單字量；預設為每天 10 個新單字。
3. 進入首頁，查看「今日任務」。
4. 先學新單字，再完成複習測驗。
5. 根據作答結果更新單字熟悉度。
6. 顯示當日完成頁與學習成果。
7. 在下次需要複習時發送提醒（需使用者授權）。

## 5. MVP 功能需求

### 5.1 功能優先級

| 優先級 | 定義 |
| --- | --- |
| P0 | 缺少就無法完成核心學習流程，MVP 必須有 |
| P1 | 明顯改善體驗，時間允許應納入 MVP |
| P2 | 加分功能，可安排在後續版本 |

| 功能 | 優先級 | 說明 | 驗收重點 |
| --- | --- | --- | --- |
| 新手引導 | P0 | 選擇目標、程度、每日字數 | 完成後會建立個人學習設定 |
| 今日學習首頁 | P0 | 顯示新字、複習數與進度 | 使用者能在一次點擊後開始學習 |
| 單字卡 | P0 | 顯示單字、音標、詞性、翻譯、例句 | 可翻面、切換上下張並播放發音 |
| 自我評估 | P0 | 使用者選擇「忘記／模糊／記得」 | 結果會影響下次複習時間 |
| 小測驗 | P0 | 中英選擇或拼字題 | 回答後立即顯示正誤與正確答案 |
| 間隔重複 | P0 | 依熟悉度安排複習 | 到期單字會出現於當日任務 |
| 本機資料儲存 | P0 | 儲存設定與學習進度 | App 重開後資料不會消失 |
| 進度統計 | P1 | 顯示連續天數、學習量、掌握量 | 統計數字與學習紀錄一致 |
| 收藏與難字本 | P1 | 將單字加入個人清單 | 可加入、移除與重新複習 |
| 每日提醒 | P1 | 使用本機通知提醒學習 | 可選擇時間、開啟或關閉 |
| 深色模式 | P1 | 支援 iOS 系統外觀 | 主要畫面在深色模式下清楚可讀 |
| 雲端同步 | P2 | 使用 iCloud 或後端同步 | 更換裝置後可恢復進度 |
| Widget | P2 | 在主畫面顯示今日進度 | 可顯示任務狀態並開啟 App |

### 5.2 單字卡內容規格

每個單字建議包含：

- 單字原文，例如 `apple`。
- 音標（可選美式或英式）。
- 詞性。
- 中文解釋。
- 英文例句與中文翻譯。
- 發音音檔或系統語音合成。
- 單字難度或所屬字庫。
- 選配：同義字、反義字、常見搭配。

### 5.3 複習規則（MVP 簡化版）

初期不一定需要複雜演算法，可先使用簡化規則：

| 使用者回饋 | 下次複習建議 |
| --- | --- |
| 忘記 | 10 分鐘後或當天再次出現 |
| 模糊 | 1 天後 |
| 記得（第 1 次） | 3 天後 |
| 記得（第 2 次） | 7 天後 |
| 記得（第 3 次以上） | 14～30 天後 |

> 未來可再導入 SM-2、FSRS 或其他間隔重複演算法。

## 7. 驗收條件範例

### 7.1 今日學習

- Given 使用者今天有 10 個新單字與 15 個待複習單字，  
  When 使用者進入首頁，  
  Then 應顯示「新單字 10」與「待複習 15」。

- Given 使用者完成一題，  
  When 回到進度畫面，  
  Then 今日已完成數量應增加 1。

### 7.2 學習紀錄

- Given 使用者對某單字選擇「忘記」，  
  When 系統儲存結果，  
  Then 該單字必須在當天再次出現，且回答紀錄不得遺失。

### 7.3 離線使用

- Given 裝置沒有網路連線，  
  When 使用者進入今日學習，  
  Then 仍能完成已下載的單字卡與測驗，並保存進度。

## 9. 非功能需求

### 9.1 效能

- 主要畫面在一般裝置上應於 1 秒內可互動。
- 單字卡切換應順暢，不得有明顯卡頓。
- 學習結果應立即儲存，避免 App 中斷時遺失。

### 9.2 無障礙與易用性

- 支援 Dynamic Type。
- 主要按鈕提供 VoiceOver 標籤。
- 不只依賴顏色傳達正確或錯誤狀態。
- 互動目標符合 iOS 可點擊範圍建議。
- 對比度應保持文字可讀性。

### 9.3 隱私與資料

- MVP 優先將個人學習資料儲存於本機。
- 只在有明確功能需求時要求通知或麥克風權限。
- 若未來加入帳號、分析工具或雲端同步，需補上隱私權政策與資料刪除機制。

### 9.4 系統支援

- 最低 iOS 版本：iOS 17。
- 介面技術：SwiftUI。
- 資料儲存：SwiftData。
- 首發裝置：iPhone。
- 畫面方向：直向為主。

## 10. 成效指標

### 10.1 核心指標

> 每週完成至少 3 天學習任務的使用者比例。

### 10.2 觀察指標

- Onboarding 完成率。
- 第一次學習任務完成率。
- 每日任務完成率。
- D1 / D7 / D30 留存率。
- 平均每次學習時間。
- 平均每週學習天數。
- 單字第一次與複習後的答對率變化。

### 10.3 MVP 成功標準

- 至少 20 名測試者完成首次學習。
- 80% 測試者不需指導就能完成一輪學習。
- 至少 40% 測試者在第 7 天仍有使用。
- 測試者每週平均完成至少 3 天的學習任務。
- 完成一輪每日學習任務的平均時間不超過 10 分鐘。
- 主要學習流程沒有會導致進度遺失的嚴重錯誤。

## 11. 內容與單字來源

### 11.1 初始字庫

- 目標字數：500 字。
- 字庫主題：日常生活高頻英文，包含人物、家庭、學校、飲食、交通、購物與時間等主題。
- 難度分級：CEFR A1～A2。
- 內容來源：第一版採用自行整理與可商業使用的開放授權資料。
- 顯示語言：英文搭配繁體中文翻譯。
- 發音方式：優先使用 iOS 內建語音合成，降低音檔容量與授權風險。

### 11.2 內容檢查

- 每個單字的詞性、翻譯與例句需經過檢查。
- 翻譯需符合目標使用者使用的繁體中文。
- 需確認字庫、音檔、字型與圖片的商業使用授權。
- 例句應簡短、自然，並展示單字的常見用法。

## 13. 風險與對策

| 風險 | 影響 | 對策 |
| --- | --- | --- |
| 單字與例句內容不準確 | 使用者失去信任 | 限制首批字庫規模，建立人工審核流程 |
| 功能過多導致無法完成 | 延遲上線 | 嚴格以 P0 完成度決定 MVP 是否可發布 |
| 間隔重複規則不合適 | 複習過多或過少 | 先使用可解釋的簡化規則，再根據數據調整 |
| 通知過於頻繁 | 關閉通知或刪除 App | 預設每日最多一次，由使用者自行設定 |
| 使用者缺乏長期動機 | 留存率低 | 縮短每日任務，強化進度回饋與可達成的小目標 |
| 資料授權不明 | 無法上架或有法律風險 | 只使用自建、已授權或條款清楚的內容 |

## 14. 第一版產品決策

| 項目 | MVP 決策 |
| --- | --- |
| 第一批使用者 | 想建立基礎單字量的高中生與大學生 |
| 初始內容 | 500 個 CEFR A1～A2 日常高頻單字 |
| 單字庫 | 第一版只提供內建字庫；自建與匯入功能留待後續版本 |
| 每日目標 | 預設 10 個新單字，使用者可自行調整 |
| 發音 | 使用 iOS 內建語音合成 |
| 帳號與同步 | MVP 不要求登入，學習資料儲存在本機 |
| 網路需求 | 完成初始安裝後，核心學習流程可離線使用 |
| 商業模式 | MVP 免費且不顯示廣告；累積使用者回饋後再評估付費方案 |
| 最低系統版本 | iOS 17 |
| 分析資料 | Beta 階段只記錄完成任務、作答結果與學習天數等必要事件，不收集敏感個資 |
| 掌握標準 | 同一單字累積答對 3 次，且最近一次間隔至少 7 天 |
| 第一版差異化 | 每日 10 分鐘、介面簡潔、離線可用，並自動安排複習 |

以上是目前的暫定決策；在使用者訪談或 Beta 測試後，可依實際回饋調整。
